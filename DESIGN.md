# GAP interface

The user's request is a similar tracker, so the referenced ARS interface establishes the visual world. Preserve navy navigation, a light work surface, clear section and status labels, and compact tabular operational data. Adapt composition for desktop with a side navigation and for phones with horizontal navigation. Do not introduce a marketing page or decorative imagery.

Use a restrained green action color for Green Anode Plant, with amber for extensions and red only for missing handovers or destructive actions. Text labels accompany status colors. Use system sans for this inherited functional interface, tabular numerals for times and order numbers, visible keyboard focus, and at least 44px control targets. Forms use a focused side panel with an explicit close button. Empty, loading, sample, disconnected, error, saving, and conflict states are first-class states. No real data appears in sample mode.
